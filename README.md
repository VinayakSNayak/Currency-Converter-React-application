# 💱 Currency Converter

A simple and responsive **Currency Converter** built with **React.js** and **Tailwind CSS**. The application uses a currency exchange API to fetch exchange rates and perform real-time currency conversions.

---

## ✨ Features

- 💰 Convert between different currencies
- 🌐 Fetch exchange rates from a currency API
- 🔄 Swap source and target currencies
- 🎯 Dynamic currency selection
- 📱 Responsive user interface
- 🧩 Reusable React components
- 🪝 Custom React Hook for API data
- ⚡ Built with Vite

---

## 🔄 How It Works

1. Select the currency to convert from.
2. Enter the amount.
3. Select the currency to convert to.
4. Click the **Convert** button.
5. The application fetches the exchange rate and calculates the converted amount.

### Example

**100 USD → INR**

The application gets the USD to INR exchange rate from the API and calculates the converted amount.

### Clone the repository

### Navigate to the project

    cd currency-converter

### Install dependencies

    npm install

### Start the development server

    npm run dev
